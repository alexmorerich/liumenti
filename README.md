## 一、六门堤水利动画

### 历史背景

**六门堤**是西汉时期修建于南阳郡穰县（今河南省邓州市）境内湍水（今湍河）上的一座大型引水工程，由汉元帝时期南阳太守**召信臣**（字翁卿）于公元前 20 年前后主持兴建。

据《汉书·循吏传·召信臣》记载：

> *"信臣为民作均水约束，刻石立于田畔，以防分争。禁止嫁娶送终奢靡，务出租税，吏民亲爱信臣，号曰'召父'。……穰、新野最为膏腴。"*

工程核心是在湍水上筑一道横向拦水大堤，坝身开凿**六个石质闸门**（即"六门"），通过控制闸门开度，将河水精确分配进主干渠及各支渠，最终灌溉穰县、新野、涅阳、山都等多个县的农田，受益面积史载数万顷，是中国古代最早的多闸门分水系统之一。

### 工程结构

```
湍水（上游来水）
    │
    ▼
六门堤（拦河坝 + 六座石闸）        ← 彭桥镇一带，穰城上游约15km
    │
    ├─── 主干渠（东向）─────────────→ 穰县城（今邓州市区）
    │         │
    │         ├─── 北支渠 ──────→ 涅阳县（今穰东镇）→ 冠军县
    │         │
    │         └─── 南支渠 ──────→ 山都县（今构林镇）→ 新野县
    │
    ├─── 北冠军渠（直接北引）───────→ 冠军县农田
    │
    └─── 分洪渠（丰水期）──────────→ 泄入低洼湿地
```

沿主干渠和支渠设有多处**陂堰**（蓄水塘），在丰水期储水、枯水期补水，实现跨季节的水量调蓄，是中国农业水利史上"蓄—引—灌"一体化思想的早期实践。

### 动画内容

动画以约 22 秒为一个完整周期，依次演示：

1. **拦河抬水** — 六门堤拦截湍水，上游水位逐渐抬升
2. **六门开闸分流** — 六个石闸依次开启，水流进入主干渠
3. **主干渠输水** — 水流沿渠向东输送至穰县及各分水口
4. **陂堰蓄调** — 沿线蓄水塘填充，平衡水量波动
5. **支渠灌田** — 水进入各县灌区，农田由枯变绿

可切换三种模式：
- **正常年景** — 六门正常开度，各灌区均匀受益
- **丰水期 / 防洪** — 闸门全开，分洪渠同时启用泄洪
- **枯水期 / 保灌** — 收窄闸门，优先保障穰县和新野主灌区

## 二、邓县三千年沿革动画

### 历史背景

邓州位于南阳盆地西南部，地处汉水支流湍河中游，北屏伏牛山，南临汉水，是连通中原与荆楚的咽喉要道。这片土地拥有超过三千年的建城史，历代政权更迭在这里留下了完整的地名层叠。

### 历史亮点

- **前678年**：楚灭邓国，是楚国北扩的重要一步，邓地正式入楚版图
- **前20年前后**：召信臣修六门堤，穰、新野成为南阳郡最富庶农业区
- **25年**：光武帝刘秀兴于南阳，邓禹等重臣出身穰地，南阳为"帝乡"
- **1045年**：范仲淹知邓州，于花洲书院著《岳阳楼记》，"先天下之忧而忧"
- **1973年**：丹江口水库竣工，古丹水流域形成大型水库，部分汉代县治淹没水下
- **1994年**：撤县设市，邓县更名邓州市，成为河南省直管县级市
- **2014年**：南水北调中线工程通水，渠首位于邓州陶岔，古六门堤灌溉传统延续至今

## 设计理念

### 地理精度优先

两个动画均放弃传统的"示意图"做法，改用**真实经纬度线性投影**：

```javascript
function gx(lon){ return (lon - LON0) / (LON1 - LON0) * canvasWidth;  }
function gy(lat){ return (LAT0 - lat) / (LAT0 - LAT1) * canvasHeight; }
```

所有城市、河流、渠道坐标均经过与汉代地图的人工校准，误差控制在 5km 以内。

### 古今双轨标注

每一处地名均同时显示**汉代地名**和**现代对应地名**，让观看者在历史与现实之间建立直观连接。例如：
- 穰县 → 今邓州市区
- 涅阳县 → 今穰东镇
- 山都县 → 今构林镇

### 动态水流可视化

水流粒子沿真实渠道路径运动，速度、密度随灌溉阶段和水文模式动态调整，直观呈现水利工程的运作逻辑。

### 零依赖

全部使用原生 Canvas 2D API，无任何第三方库，文件体积小，加载即用，适合嵌入任何页面。
